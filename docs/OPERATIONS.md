## 1. 유지보수를 쉽게 하는 설계 원칙

| 원칙 | 구체적으로 |
|---|---|
| 콘텐츠와 코드 분리 | 단어·퍼즐은 DB/관리자에서, 앱 코드에는 없음 → 콘텐츠 수정에 앱 업데이트 불필요 |
| 하나의 코드, 여러 플랫폼 | 웹·Android·iOS·관리자가 엔진·UI 공유 (모노레포) |
| 게임 로직은 순수 TypeScript | 화면과 분리 → 테스트로 보호, 리팩터링 안전 |
| 플랫폼 차이는 어댑터 한 곳에 | 저장·발음·진동·알림은 `shared/platform`에서만 분기 |
| 원격 설정으로 끄는 스위치 | 새 기능은 기본적으로 원격 설정 플래그 뒤에 출시 |
| 오프라인 우선 | 서버 장애가 게임 장애가 되지 않음 |
| 자동화된 품질 관문 | PR마다 타입 검사·린트·테스트·콘텐츠 검사 통과해야 머지 |
| 결정은 문서로 | ADR(결정 기록), 장애 대응 매뉴얼(runbook), CHANGELOG |

## 2. 데이터 버전 관리 (깨지지 않는 업데이트)

| 대상 | 방식 |
|---|---|
| DB 구조 | Supabase 마이그레이션 파일을 Git으로 관리, PR 리뷰 후 적용. 직접 수정 금지 |
| 콘텐츠 | 발행마다 `content-vN` 묶음. 앱은 지원하는 **스키마 버전**의 콘텐츠만 받음 |
| 기기 저장 데이터 | 저장 형식에 `schemaVersion`. 앱 업데이트 시 변환 코드(migration) 실행, 테스트 필수 |
| 스테이지 ID | 공개 후 변경·삭제 금지(숨김만) → 사용자 진행 기록 보호 |

## 3. 모니터링 · 알림

| 무엇을 | 도구 | 알림 기준 (예) |
|---|---|---|
| 앱 오류(크래시·JS 오류) | Sentry | 새 오류 유형 발생, 오류 사용자 1% 초과 |
| 서버 상태·DB 사용량 | Supabase 대시보드 · 로그 | 무료 한도 80% 도달 |
| 웹 배포 | Vercel | 빌드 실패 |
| 핵심 지표 | 관리자 대시보드 | DAU 급감(전주 대비 -30%), 특정 스테이지 중단율 급증 |
| 스토어 | Play Console · App Store Connect | 별점 3.5 미만 리뷰, ANR/크래시율 경고 |

알림은 이메일(필요 시 Slack/카카오워크 연동)로 받습니다.

## 5. 릴리스 절차

### 5.1 종류별 경로
| 변경 종류 | 경로 | 반영 속도 |
|---|---|---|
| 단어·퍼즐·공지 | 관리자에서 발행 | 다음 앱 실행 |
| 기능 켜기/끄기, 수치 조정 | 원격 설정 | 다음 앱 실행 |
| 화면·로직 수정 | 앱 업데이트 (스토어 심사) | 1~3일 |
| 긴급 웹 계층 수정 (선택) | Capacitor 실시간 업데이트(Capgo 등) | 즉시 — 단, **스토어 정책상 버그 수정 범위만**, 기능 추가는 반드시 심사 |

### 5.2 앱 업데이트 단계
1. `main` 머지 → CI 통과 → 버전 번호·CHANGELOG 갱신
2. Android: 내부 테스트 트랙 → (확인) → 단계적 출시 10% → 50% → 100%
3. iOS: TestFlight → 심사 → 단계적 출시(7일)
4. 문제 발생 시: 단계적 출시 중지 + 원격 설정으로 해당 기능 끄기 → 수정판

## 6. 백업 · 장애 대응

| 항목 | 계획 |
|---|---|
| DB 백업 | Supabase 일일 백업 (유료 플랜 전환 시 시점 복구), 추가로 주 1회 콘텐츠 JSON 내보내기를 Git 저장소에 자동 커밋 |
| 콘텐츠 복구 | 발행 버전 롤백 (관리자 1클릭) |
| 서버 장애 | 게임은 내장 콘텐츠로 계속 동작. 로그는 기기에 쌓았다가 복구 후 전송 |
| 장애 대응 매뉴얼 | `docs/runbook.md`: 앱 오류 급증 / 서버 다운 / 잘못된 콘텐츠 발행 / 관리자 계정 유출 시 절차 |

## 7. 보안

- 관리자: 2단계 인증 필수, 최소 권한, 퇴사·종료 시 즉시 비활성화
- DB: 모든 테이블에 권한 규칙(RLS) 적용, 게임 앱 키로는 공개 콘텐츠 읽기 + 로그 쓰기만 가능
- 비밀 키는 코드에 넣지 않음 (GitHub Secrets / Vercel 환경변수)
- 의존성 취약점 자동 검사 (Dependabot, `npm audit` CI)
