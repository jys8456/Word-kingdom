## 1. 왜 관리자 화면이 필요한가

관리자 화면이 없으면 **단어 하나 고칠 때마다 개발자가 코드를 수정하고 앱을 다시 심사받아야** 합니다.

| 운영 상황 | 관리자 없이 | 관리자 있으면 |
|---|---|---|
| 뜻·예문 오타 수정 | 코드 수정 → 빌드 → 스토어 심사 (1~3일) | 수정 → 발행 → **다음 앱 실행 때 반영** |
| 새 테마 추가 | 개발자가 JSON 직접 작성 | 퍼즐 에디터로 배치, 자동 검사 후 발행 |
| 어려운 스테이지 파악 | 로그 파일을 직접 분석 | 대시보드에서 스테이지별 중단율 확인 |
| 버그 있는 기능 끄기 | 긴급 업데이트 + 심사 | 원격 설정에서 끄기 |
| 공지·이벤트 | 앱 업데이트 | 공지 등록 |
| 사용자 문의 "진행이 사라졌어요" | 확인 방법 없음 | 기기 ID로 진행 기록 조회 |

## 2. 사용자와 권한

| 역할 | 할 수 있는 일 | 예상 인원 |
|---|---|---|
| **Owner** | 전체 + 관리자 계정 관리 + 원격 설정 + 데이터 삭제 | 1 (프로젝트 오너) |
| **Editor** | 단어·퍼즐 작성/수정, 검수 요청, 공지 작성 | 1~3 (콘텐츠 작성자) |
| **Reviewer** | 콘텐츠 검수·승인·발행 | 1~2 |
| **Viewer** | 대시보드·콘텐츠 읽기 전용 | 필요 시 |

- 로그인: 이메일 + 비밀번호 + **2단계 인증(OTP)**. 관리자 계정은 Owner가 초대해서만 생성.
- 게임 사용자는 관리자 화면에 접근할 수 없다 (서버 권한 규칙으로 차단, §6).
- **모든 변경은 변경 이력(audit log)에 남는다:** 누가 · 언제 · 무엇을 · 이전 값 → 새 값.

## 4. 기능 요구사항

> 우선순위: **A1** = MVP 사용자 테스트 전 필수 · **A2** = 스토어 출시 전 · **A3** = 출시 후

### AD-01 대시보드 — A1
| 지표 | 표시 | 연결 가설 |
|---|---|---|
| DAU / 신규 설치 | 일별 선 그래프 | – |
| D1 / D3 / D7 재방문 | 설치일 기준 코호트 표 | H1 |
| 다음 스테이지 자발 진입률 | 스테이지별 막대 | H1 |
| 스테이지 퍼널 | 시작 → 완료 / 중단 / 건너뛰기 | H1 |
| 힌트 사용률 | 스테이지별 · 힌트 단계별 | 난이도 |
| 어려운 단어 Top 20 | 오답률 높은 순 | 콘텐츠 수정 |
| 학습 테스트 결과 | 회상형 vs 노출형 정답률 | H2 |
- AC1. 기간 필터(오늘 / 7일 / 30일 / 직접 선택), 앱 버전·플랫폼 필터
- AC2. 표 데이터를 CSV로 내려받기
- AC3. 스테이지 / 단어를 누르면 해당 콘텐츠 편집 화면으로 이동

### AD-02 단어 사전 — A1
단어를 **한 곳에서 관리**하고 여러 테마·스테이지에서 재사용.
- 필드: 영어 단어 · 한국어 뜻(1~2개) · 예문 · 예문 해석 · 어휘 수준(중학/수능/토익) · 품사 · 음성 파일(단어/예문) · 태그 · 상태
- AC1. 검색(영어/한국어), 필터(수준·상태·테마), 정렬
- AC2. 예문에 단어가 없으면 저장 불가 (게임과 같은 검사 규칙 사용)
- AC3. CSV/엑셀 일괄 가져오기 · 내보내기
- AC4. 어떤 스테이지에서 쓰이는지 역참조 표시

### AD-03 테마 · 스테이지 — A1
- 테마: 이름(영/한) · 어휘 수준 · 배경 모티프 · 순서 · 공개 여부
- 스테이지: 순서 드래그 정렬 · 제목 · 모드(크로스워드/워드서치/복습 템플릿)
- AC1. 스테이지별 지표(중단율·평균 별·힌트 사용률)를 목록에서 바로 표시 → 문제 스테이지가 눈에 띄게

### AD-04 퍼즐 에디터 — A2 (A1에서는 JSON 붙여넣기 + 자동 검사로 대체)
```
┌───────────────┬─────────────────────┬──────────────┐
│ 단어 목록      │   격자 편집 (7×8)    │ 게임 미리보기 │
│ (단어 사전에서 │  단어를 끌어다 놓기   │ (360폭 실제  │
│  검색·추가)    │  가로/세로 전환       │  게임 화면)  │
│ ☐ SHUFFLE     │                     │              │
│ ☑ DEAL        │                     │              │
├───────────────┴─────────────────────┴──────────────┤
│ 검사 결과: ✅ 연결됨 ✅ 글자 일치 ⚠️ 7열 초과       │
└────────────────────────────────────────────────────┘
```
- AC1. 단어를 격자에 놓으면 교차 글자가 맞는지 실시간 검사
- AC2. **배치 추천** 버튼: 선택한 단어로 가능한 배치 후보 3개 제시 → 사람이 고름 (자동 생성 아님, 작성 보조)
- AC3. 오른쪽에 실제 게임 컴포넌트로 미리보기 (게임과 같은 코드 사용)
- AC4. 검사 오류가 있으면 검수 요청 불가

### AD-05 음성 파일 — A2
- AC1. 단어·예문별 음성 파일 업로드, 또는 TTS로 일괄 생성 (서비스 선택은 D-A3)
- AC2. 재생 확인, 누락 목록 표시
- AC3. 발행 시 음성 누락이 있으면 경고

### AD-06 발행 관리 — A1
콘텐츠는 **초안 → 검수 요청 → 승인 → 발행** 단계를 거친다.
- AC1. 발행 = 콘텐츠 묶음(버전 번호 `content-v12`) 생성 → 앱이 다음 실행 때 내려받음
- AC2. 이전 버전으로 **1클릭 롤백**
- AC3. 발행 전 차이 비교(무엇이 바뀌었는지)
- AC4. 진행 중인 사용자의 진행 기록이 깨지지 않도록, 이미 공개된 스테이지 ID는 삭제 불가(숨김만 가능)

### AD-07 공지 · 이벤트 배너 — A2
- 제목 · 내용 · 노출 기간 · 대상(플랫폼/앱 버전) · 노출 위치(지도 상단 배너 / 1회 팝업)
- AC1. 퍼즐 화면에는 절대 노출되지 않음 (PRD 원칙 7)

### AD-08 원격 설정 — A1
앱 업데이트 없이 바꿀 수 있는 값.
| 키 예시 | 값 | 용도 |
|---|---|---|
| `feature.wordsearch` | on/off | 문제 생기면 즉시 끄기 |
| `feature.review` | on/off | |
| `review.delayHours` | 48 | 복습 간격 조정 |
| `stars.thresholds` | [0,2] | 별 기준 조정 |
| `analytics.enabled` | on/off | 수집 중단 |
- AC1. 변경 시 확인 단계 + 변경 이력 기록
- AC2. 앱은 서버 연결이 안 되면 **마지막 값 → 앱 내장 기본값** 순으로 사용 (오프라인에서도 동작)

### AD-09 앱 버전 관리 — A2
- 최소 지원 버전 설정 → 그보다 낮으면 "업데이트 필요" 화면 (강제 / 권장 선택)
- 버전별 사용자 수 표시 → 구버전 지원 종료 판단

### AD-10 사용자 지원 — A3
- 기기 ID(앱 설정 화면에 표시되는 짧은 코드, 예: `WK-7F3A`)로 진행 기록·최근 이벤트·오류 조회
- 앱 내 "의견 보내기"로 들어온 피드백·오류 신고 목록, 처리 상태(신규/확인/완료)
- 개인정보 원칙: 이름·이메일 등은 **수집하지 않음**. 사용자가 피드백에 연락처를 직접 쓴 경우만 보관하고, 90일 뒤 삭제

### AD-11 실험 관리 — A2
- 학습 테스트(F-10) 그룹 배정 비율, 테스트 시점(5~7일), 문항 수 설정
- 결과 요약은 대시보드(AD-01)와 연결

### AD-12 관리자 계정 · 변경 이력 — A1
- 초대, 역할 변경, 비활성화, 2단계 인증 강제
- 변경 이력: 대상 · 변경 전/후 · 작업자 · 시각, 검색 가능, 삭제 불가

## 6. 구조 (요약 — 상세는 DEV_PLAN §2, §3)

```
┌──────────────┐      콘텐츠 묶음(JSON) 내려받기      ┌────────────────────┐
│  게임 앱      │ ◀──────────────────────────────── │                    │
│ (웹/Android/ │ ──── 이벤트 로그 · 피드백 올리기 ──▶ │  Supabase          │
│  iOS)        │ ◀──── 원격 설정 · 공지 ──────────── │  · DB (Postgres)   │
│ 오프라인 우선 │                                    │  · 인증 (관리자)    │
└──────────────┘                                    │  · 파일 (음성)      │
                                                     │  · 서버 함수        │
┌──────────────┐    읽기/쓰기 (관리자 로그인 필수)    │  · 권한 규칙(RLS)   │
│  관리자 웹    │ ◀───────────────────────────────▶ │                    │
└──────────────┘                                    └────────────────────┘
        ▲ 같은 퍼즐 엔진·검사 규칙·UI 컴포넌트 공유 (packages/engine, packages/ui)
```

- 게임 앱은 **회원가입 없이** 익명 기기 ID로만 통신. 콘텐츠는 앱에 기본 내장 + 새 버전만 내려받음 → 서버가 꺼져도 게임은 됨.
- 관리자 웹은 별도 주소(예: `admin.<도메인>`), 검색엔진 노출 차단.
- 게임 앱은 **읽기 전용 공개 데이터 + 로그 쓰기만** 가능하도록 서버 권한 규칙으로 막음.
