# WORD KINGDOM — 코드 세션 인계 브리프

> 이 문서를 새 코드 세션 첫 메시지에 붙여 넣으세요. 기획 대화의 결론만 담았습니다.

## 1. 한 줄 콘셉트
한국인 초중급 영어 학습자를 위한 **테마별 영어 단어 퍼즐 스테이지 게임**.
"공부하려고 켠 게 아닌데, 한 판 더 하다 보니 단어를 기억하게 되는" 경험이 목표.

## 2. 출발점 / 맥락
- 비행기 옆자리 승객이 영어 종합 퍼즐북(크로스워드, 애로워드, 워드서치, 글자 잇기)을 푸는 걸 보고 착안.
- Royal Kingdom처럼 스테이지를 하나씩 깨 나가는 진행감을 원함.
- 경쟁작: Wordscapes(퍼즐), 말해보카(학습). 직접 Wordscapes를 플레이해 본 결과 아래 문제점 확인.

## 3. Wordscapes 직접 플레이 관찰 → 설계 원칙
| Wordscapes 문제 | WORD KINGDOM 원칙 |
|---|---|
| 판 끝나면 코인·광고만, 단어 리캡 없음 | 완료 화면에 "이번 판 단어 3개 + 🔊 발음" |
| 사전이 Aa 버튼 뒤에 숨은 긴 영영 뜻 | 정답 순간 한 줄 카드: 한국어 뜻 · 발음 · 짧은 예문 |
| 낱말잇기만 반복, 다양성 없음 | 크로스워드 / 애로워드 / 워드서치를 스테이지마다 섞기 |
| 틀려도 페널티 없음 (막 스와이프) | 가벼운 긴장감: 실수 시 별·콤보 감소 (목숨제 X) |
| 발음 없음 | 정답 시 자동 발음 재생 (Web Speech API로 시작) |
| PAL/PAN/LAW 등 너무 쉬운 단어, 난이도=애너그램 | 난이도는 어휘 수준(중학→수능→토익)으로, 퍼즐 자체는 쉽게 |
| Word Drop: 규칙이 ? 버튼 뒤에 숨음, 보상이 운 | 새 모드 첫 진입 시 강제 미니 튜토리얼, 보상은 실력 연동 |
| 실제 영어 단어인데 오답 처리 | 사전에 있는 단어는 보너스로 인정 |
| 도전 후 나가기/스킵 불가 | 언제든 나가기·건너뛰기 |
| 모든 화면 배너 광고 | 퍼즐 중 광고 없음 |

**살릴 것**
- 나비 찾기 → 응용: **지난번 틀린 단어 칸에 수집품을 숨겨** 복습 = 수집이 되게.
- 경주(누가 먼저 도달) 이벤트.
- 레벨 오르면 메뉴 하나씩 해금.

## 4. 핵심 설계 결정 (리뷰 결론)
1. 타깃: 한국인 초중급 성인, 어휘 범위 고정 (중학~수능 기본).
2. 힌트 = 한국어 뜻, 답 = 영어 철자 → 모든 퍼즐이 '회상 연습'이 되게.
   - 워드서치도 찾을 목록을 **한국어 뜻**으로 표시 (예: "섞다" → SHUFFLE 찾기).
3. 입력은 키보드 대신 글자 타일/휠.
4. 주력 모드: 미니 크로스워드(5×5 내외). 워드서치는 몸풀기.
5. 메타: 왕국 건설 대신 테마 지도 + 단어 도감 (도감 = 학습 진척).
6. 힌트 유료화 금지. 힌트 단계: 첫 글자 → 한국어 뜻 강조 → 예문.

## 5. 2주 MVP 범위 (웹 프로토타입, 모바일 브라우저 우선)
**만들 것**
- 미니 크로스워드 엔진 (한국어 뜻 힌트, 글자 타일 입력)
- 한국어 뜻 목록형 워드서치 (보조 모드)
- 3개 테마 × 10스테이지, 지도 위 스테이지 점 해금
- 정답 시 한 줄 단어 카드 + 발음
- 레벨 완료 화면 단어 리캡
- 틀린 단어 기록 → 2~3일 뒤 복습 스테이지에 재출제 (수집품 숨김)
- 단어 도감
- 이벤트 로깅: 시작/포기/완료/힌트 사용/재방문 (localStorage + 간단한 export)

**빼야 할 것**
- 건설 화면, 재화 상점, 광고, 결제, 앱스토어 출시, 자동 퍼즐 생성기(초기 퍼즐은 손으로 배치), 실시간 AI

**측정할 것**
- 다음 스테이지 자발 진입률, 중단 지점, 힌트 사용률, D1/D3 재방문
- 학습: 단어 절반은 '노출만', 절반은 '회상 문제' → 5~7일 뒤 힌트 없는 테스트로 비교

## 6. 기술 제안 (코드 세션에서 확정)
- 정적 웹앱 (예: Vite + TypeScript, 또는 단일 HTML로 시작)
- 콘텐츠는 JSON: `{ theme, stages: [{ type: "crossword"|"wordsearch", grid, entries: [{ answer, ko, example, row, col, dir }] }] }`
- 발음: 브라우저 `speechSynthesis` (en-US)
- 진행/로그 저장: localStorage (try/catch)

## 7. 예시 콘텐츠 (가상)
테마 "Deck of Cards": ACE(에이스), SUIT(카드 무늬), DECK(카드 한 벌), SHUFFLE(섞다)
- 워드서치: 한국어 뜻 목록으로 찾기
- 크로스워드: "카드를 섞다" → SHUFFLE
- 복습: "Please ____ the cards before we play."

## 8. 첫 작업 요청 (코드 세션에 그대로 지시)
1. 위 JSON 구조로 테마 1개(10스테이지) 샘플 데이터 작성
2. 모바일 우선 미니 크로스워드 화면 + 글자 타일 입력 구현
3. 정답 카드(뜻·발음·예문)와 완료 리캡 화면
4. 스테이지 지도와 진행 저장
