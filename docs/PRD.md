## 1. 제품 개요

### 1.1 한 줄 정의
한국인 초중급 영어 학습자를 위한 **게임처럼 재미있는 영어 단어 공부 앱** — 테마별 단어 퍼즐 스테이지로 진행.

- 정체성: **영어공부 앱** (스토어 카테고리: 교육). 게임 요소는 꾸준히 하게 만드는 수단.
- 사업 목표: **수익을 내는 서비스** (수익 모델은 Q18 답변 후 확정, MVP에서는 결제 미구현).

### 1.2 비전
> "공부하려고 켠 게 아닌데, 한 판 더 하다 보니 단어를 기억하게 되는" 경험.

### 1.3 배경
- 영어 종합 퍼즐북(크로스워드·애로워드·워드서치)을 푸는 사람을 보고 착안.
- 퍼즐 게임(Wordscapes)은 재미있지만 **학습이 남지 않고**, 학습 앱(말해보카)은 **공부라는 부담**이 있음.
- 그 사이: **퍼즐의 몰입감 + 학습 앱의 기억 효과**.

### 1.4 경쟁작 분석 (직접 플레이 관찰)

| 경쟁작 문제 | 우리의 원칙 | 관련 요구사항 |
|---|---|---|
| 판 끝나면 코인·광고만, 단어 리캡 없음 | 완료 화면에 이번 판 단어 + 🔊 발음 | F-05 |
| 사전이 버튼 뒤에 숨은 긴 영영 뜻 | 정답 순간 한 줄 카드: 한국어 뜻·발음·예문 | F-04 |
| 낱말잇기만 반복 | 크로스워드 / 워드서치(→ 애로워드) 섞기 | F-02, F-03 |
| 틀려도 페널티 없음 → 막 스와이프 | 실수 시 별·콤보 감소 (목숨제 X) | F-02 |
| 발음 없음 | 정답 시 자동 발음 | F-04 |
| 너무 쉬운 단어, 난이도 = 애너그램 | 난이도 = 어휘 수준(중학→수능→토익), 퍼즐 자체는 쉽게 | §7 콘텐츠 |
| 새 모드 규칙이 ? 버튼 뒤에 숨음 | 새 모드 첫 진입 시 강제 미니 튜토리얼 | F-09 |
| 실제 영단어인데 오답 처리 | 사전에 있는 단어는 보너스 인정 | F-03 (워드서치) |
| 도전 후 나가기/스킵 불가 | 언제든 나가기·건너뛰기 | F-02 |
| 모든 화면 배너 광고 | 퍼즐 중 광고 없음 | §9 비기능 |

**살릴 것:** 숨은 수집품 찾기(→ 틀린 단어 칸에 수집품 = 복습이 곧 수집), 레벨업 시 메뉴 하나씩 해금, 경주 이벤트(MVP 이후).

## 2. 목표와 성공 지표

### 2.1 MVP의 목적
MVP는 출시용이 아니라 **두 가지 가설을 검증하는 실험**입니다.

| # | 가설 | 검증 지표 | 성공 기준 (제안, 승인 필요) |
|---|---|---|---|
| H1 | 사람들이 **자발적으로 "한 판 더"** 한다 | 다음 스테이지 자발 진입률 | 완료 후 60% 이상이 바로 다음 스테이지 진입 |
| | | D1 / D3 재방문율 | D1 40% / D3 25% 이상 |
| | | 스테이지 중단율 | 스테이지별 중단 20% 미만 (넘는 스테이지는 콘텐츠 수정) |
| H2 | 퍼즐로 푼 단어가 **실제로 기억에 남는다** | 5~7일 뒤 힌트 없는 테스트 정답률: 회상형 vs 노출형 | 회상형이 노출형보다 15%p 이상 높음 |

### 2.2 보조 지표
- 힌트 사용률 (스테이지별 / 힌트 단계별) → 난이도 조정 근거
- 스테이지 평균 플레이 시간 (목표: 1판 2~4분)
- 발음 버튼 재생 횟수 → 발음 기능 가치 판단

### 2.3 하지 않을 것 (Non-goals)
- 게임 사용자 로그인은 **사용자 테스트(MVP)에는 없음**, 출시 버전에서 선택 사항으로 추가 (F-13)
- MVP에서의 결제·광고 구현 (단, **수익화를 전제로 구조는 설계**: 테마 단위 잠금/해제, 상품 정보 원격 관리 자리 확보)
- 소셜 로그인, 랭킹, 실시간 AI, 자동 퍼즐 생성기, 왕국 건설 화면

## 3. 타깃 사용자

### 3.1 페르소나

**① 지수 (29세, 직장인) — 주 타깃**
- 수능 이후 영어 손 놓음. 토익 600점대. "단어 외워야지" 생각만 함.
- 출퇴근 지하철에서 한 손으로 폰 게임(애니팡, 퍼즐류)을 함.
- 니즈: 부담 없이, 짧게, 그래도 뭔가 남는 것.
- 페인: 단어장 앱은 3일 만에 지움. 영영 사전은 읽기 싫음.

**② 민준 (16세, 중학생) — 비주력 (Q5: 성인 중심으로 결정)**
> 사용은 가능하지만 기능·문구·마케팅은 성인 기준으로 설계한다.
- 학원 숙제 단어가 지루함. 게임은 좋아함.
- 니즈: 게임처럼 진행감, 별 모으기.
- 주의: 미성년자 → 개인정보 수집 최소화 (§9.3).

### 3.2 어휘 범위
- MVP: **중학 ~ 수능 기본 어휘**로 고정. (토익은 이후 테마로 확장)

## 4. 핵심 설계 원칙

1. **힌트 = 한국어 뜻, 답 = 영어 철자.** 모든 퍼즐이 '회상 연습'이 되게 한다. 워드서치도 찾을 목록을 한국어 뜻으로 표시.
2. **입력은 키보드가 아닌 글자 타일.** 한 손 조작, 오타 스트레스 제거.
3. **퍼즐은 쉽게, 어휘로 난이도.** 격자는 5×5 내외, 머리 쓰는 곳은 "이 뜻의 영어 단어가 뭐였지?"
4. **틀림에는 가벼운 긴장감만.** 별·콤보 감소. 게임 오버 없음.
5. **힌트는 절대 유료화하지 않는다.** 단계: 첫 글자 → 빈칸 예문 → 가짜 글자 제거.
6. **언제든 나갈 수 있다.** 나가기·건너뛰기 항상 노출.
7. **퍼즐 중엔 아무것도 끼어들지 않는다.** 광고·팝업 없음.

## 6. 기능 요구사항 (유저 스토리 + 인수 조건)

> 인수 조건(AC)이 모두 충족되어야 해당 기능을 "완료"로 본다. 화면 상세는 [UX_SPEC.md](./UX_SPEC.md).

### F-01 테마 지도
**스토리:** 사용자로서, 지금 어디까지 왔고 다음에 뭘 할지 한눈에 보고 싶다.
- AC1. 스테이지 1은 항상 열려 있다. 스테이지 N은 N-1을 **클리어 또는 건너뛰기**하면 열린다.
- AC2. 각 스테이지 점은 상태를 구분해 보여준다: 잠김 / 현재 / 클리어(별 0~3) / 건너뜀.
- AC3. 앱 진입 시 '현재' 스테이지가 화면 중앙에 오도록 스크롤된다.
- AC4. 상단에 총 별 수, 도감 진척(본 단어 / 전체 단어)을 표시한다.
- AC5. 복습 스테이지가 준비되면 지도에 별도 표시된다 (F-06).

### F-02 미니 크로스워드
**스토리:** 사용자로서, 한국어 뜻을 보고 영어 단어를 떠올려 칸을 채우고 싶다.
- AC1. 격자는 최대 7열 × 8행, 단어 3~6개. 모든 단어는 서로 연결되어 있다.
- AC2. 현재 풀 단어의 칸이 강조되고, 단서 바에 `번호 · 가로/세로 · 글자 수 · 한국어 뜻`이 보인다.
- AC3. 글자 타일 = 남은 칸의 정답 글자 + 가짜 글자 1~2개, 섞어서 표시.
- AC4. 타일을 누르면 다음 빈 칸에 채워진다. 지우기(⌫)로 마지막 글자를 되돌린다.
- AC5. 칸이 다 차면 자동 채점. 정답 → 칸 고정 + 단어 카드(F-04). 오답 → 칸 흔들림 + 진동 + 실수 1 증가 + 콤보 0, 글자는 타일로 되돌아간다.
- AC6. 별: 실수 0 = ★3, 1~2 = ★2, 3+ = ★1. 현재 별은 상단에 실시간 표시.
- AC7. 힌트(무료) 3단계: ① 첫 빈 글자 공개 ② 빈칸 예문 표시 ③ 가짜 글자 제거. 힌트는 별에 영향 없음.
- AC8. 다른 칸을 누르면 그 칸의 단어로 전환된다. ‹ › 버튼으로 이전/다음 미해결 단어 이동.
- AC9. 나가기(✕)는 확인 없이 지도로. 건너뛰기는 2번 탭으로 확인 → 다음 스테이지 해금, 별 0.
- AC10. 360×640 화면에서 스크롤 없이 모든 요소가 보인다.

### F-03 워드서치 (몸풀기)
**스토리:** 사용자로서, 가볍게 몸풀기로 한국어 뜻에 맞는 단어를 찾고 싶다.
- AC1. 6×6~8×8 격자, 찾을 목록은 **한국어 뜻**으로 표시 (예: "섞다" → SHUFFLE).
- AC2. 손가락 드래그로 가로·세로·대각선 선택.
- AC3. 목록에 없지만 사전에 있는 실제 단어(3글자 이상)를 찾으면 **보너스**로 인정, 별도 표시.
- AC4. 찾으면 단어 카드(F-04)를 짧게 표시 (워드서치는 하단 토스트형).
- AC5. 테마당 10스테이지 중 1·4·7번을 워드서치로 배치 (제안).

### F-04 정답 단어 카드
**스토리:** 사용자로서, 맞힌 순간 그 단어의 뜻·발음·쓰임을 짧게 확인하고 싶다.
- AC1. 영어 단어(크게) · 🔊 · 한국어 뜻 · 예문(정답 단어 강조) · 예문 🔊 · [계속].
- AC2. 카드가 뜨면 단어를 **자동 발음** (설정에서 끌 수 있음).
- AC3. 콤보 2 이상이면 "콤보 ×N" 배지.
- AC4. 바깥 탭 또는 [계속]으로 닫힘. 3초 이상 강제 대기 없음.

### F-05 완료 리캡
**스토리:** 사용자로서, 판이 끝나면 이번에 만난 단어를 다시 한번 보고 싶다.
- AC1. 별 애니메이션, 실수·힌트 수, 이번 판 단어 전체(영어·뜻·🔊).
- AC2. 이번 판에 틀렸던 단어에는 '복습' 태그.
- AC3. [다음 스테이지 ▶]가 주 버튼, [지도로]가 보조 버튼.
- AC4. 다음 스테이지 버튼 탭은 `next_stage` 이벤트로 기록 (H1 지표).

### F-06 복습 스테이지 + 숨은 수집품
**스토리:** 사용자로서, 지난번에 틀린 단어를 다시 만나 확실히 내 것으로 만들고 싶다.
- AC1. 틀린 단어는 기록되며, 마지막으로 틀린 지 **48시간 이후** 복습 대상이 된다.
- AC2. 복습 대상이 4개 이상 쌓이면 지도에 복습 스테이지가 생긴다.
- AC3. 복습 스테이지는 손으로 만든 '복습용 격자 템플릿'에 대상 단어를 배치한다 (자동 생성기 아님 — 단어 길이별 템플릿 매칭).
- AC4. 복습 단어 칸에는 **수집품(카드 문양 등)**이 숨어 있고, 맞히면 획득해 도감에 기록된다.
- AC5. 복습에서 맞힌 단어는 복습 목록에서 빠진다. 또 틀리면 48시간 뒤 다시 등장.

### F-07 단어 도감
- AC1. 테마별로 만난 단어 목록 (안 만난 단어는 실루엣 `? ? ? ?`).
- AC2. 단어별 상태: 처음 봄 / 틀린 적 있음 / 복습 완료(⭐ 마스터).
- AC3. 단어 탭 시 단어 카드(F-04)와 동일한 상세.
- AC4. 획득한 수집품 모음.

### F-08 저장·로깅
- AC1. 진행·별·틀린 단어·도감·설정은 기기 안에 저장 (오프라인 동작).
- AC2. 저장 실패 시에도 게임은 중단되지 않는다.
- AC3. 이벤트 로그 (§8)를 기기에 쌓고, 설정 화면에서 JSON으로 내보낼 수 있다.
- AC4. 테스트 기간 중 지표 수집을 위해 원격 전송을 켤 수 있다 (§9.3 개인정보 조건 충족 시).

### F-09 튜토리얼
- AC1. 각 모드(크로스워드·워드서치·복습) **첫 진입 시 1회** 강제 표시, 3단계 이내.
- AC2. 설정에서 다시 볼 수 있다.

### F-10 학습 효과 테스트
- AC1. 각 테마 단어의 절반은 '회상형'(퍼즐 정답), 절반은 '노출형'(카드·리캡에서만 봄)으로 사용자별 무작위 배정.
- AC2. 첫 플레이 5~7일 뒤 앱 진입 시 "1분 단어 체크" 제안 (거절 가능).
- AC3. 한국어 뜻 → 영어 철자 입력(힌트 없음) 10문항. 결과는 로그로 기록.
- ⚠️ 노출형 단어를 퍼즐 정답에서 빼야 하므로 콘텐츠 설계에 영향 → **§13 결정 필요**.

### F-11 설정
자동 발음, 효과음, 진동 on/off · 튜토리얼 다시 보기 · 학습 기록 내보내기 · 데이터 초기화 · 의견 보내기 · 기기 코드(문의용, 예: `WK-7F3A`) · 개인정보 처리방침 · 버전 정보

### F-13 계정 · 기록 백업 (출시 버전)
**스토리:** 사용자로서, 휴대폰을 바꿔도 내 학습 기록을 이어가고 싶다.
- AC1. 로그인은 **선택 사항**. 로그인 없이도 모든 기능을 쓸 수 있다.
- AC2. 설정에서 Google 로그인 → 기기의 기록을 서버에 백업, 다른 기기에서 로그인하면 복원.
- AC3. 앱 안에서 **계정 삭제** 가능 (스토어 정책 필수), 삭제 시 서버 기록도 삭제.
- AC4. iOS 출시 시 Apple 로그인 추가 (Apple 정책: 다른 소셜 로그인을 제공하면 필요).
- AC5. 유료 구매가 생기면 구매 복원은 스토어 기능으로 처리.

### F-12 콘텐츠 원격 업데이트
**스토리:** 운영자로서, 앱 업데이트 없이 단어·퍼즐을 고치고 새 테마를 내보내고 싶다.
- AC1. 앱에는 출시 시점 콘텐츠가 내장되어 있어 첫 실행·오프라인에서도 플레이 가능.
- AC2. 앱 실행 시 서버의 최신 콘텐츠 버전을 확인하고, 새 버전이 있으면 백그라운드로 내려받아 **다음 화면 전환 시** 적용 (플레이 중인 퍼즐은 바뀌지 않음).
- AC3. 원격 설정·공지도 같은 방식. 서버 연결 실패 시 마지막 값 → 내장 기본값.
- AC4. 이벤트 로그는 기기에 쌓았다가 연결될 때 묶어서 전송 (실패 시 재시도, 최대 보관량 제한).

### 7.1 데이터 형식
```jsonc
{
  "id": "deck-of-cards", "theme": "Deck of Cards", "themeKo": "카드 한 벌",
  "level": "middle",                       // middle | csat | toeic
  "stages": [{
    "id": "cards-01", "title": "카드 첫걸음",
    "type": "crossword",                   // crossword | wordsearch | review
    "grid": ["CARD", ".C..", "DECK"],      // '.' = 빈칸
    "entries": [{
      "answer": "ACE", "ko": "에이스 (카드의 1)",
      "example": "She has an ace in her hand.",
      "exampleKo": "그녀는 손에 에이스를 들고 있다.",   // 추가 제안
      "row": 0, "col": 1, "dir": "down"
    }]
  }]
}
```

### 7.2 품질 기준 (자동 검사 + 사람 검수)

**작성·검수 절차:** Claude가 초안(단어·뜻·예문·퍼즐 배치) 작성 → 자동 검사 → **오너 검수** → 발행. 영어공부 앱이므로 뜻·예문의 정확성이 최우선이며, 오너가 승인하지 않은 콘텐츠는 발행하지 않는다.

- 자동: 격자-정답 일치, 단어 연결성, 예문에 정답 포함, 테마 내 중복 없음, 최대 7×8
- 사람: 한국어 뜻은 **가장 흔한 뜻 1~2개**만, 예문은 **10단어 이내 + 중학 수준 문법**, 성별·인종 고정관념 없는 문장
- 발음: 단어·예문 오디오 품질 확인 (§DEV_PLAN 4.4)

## 9. 비기능 요구사항

### 9.1 플랫폼
- **1단계:** 모바일 웹 (PWA) — 사용자 테스트용 링크 배포
- **2단계:** Android (Google Play) → **3단계:** iOS (App Store). 상세는 DEV_PLAN §6.
- 지원: Android 8+ (Chrome/WebView 최신), iOS 15+, 화면 360×640 이상, 세로 고정

### 9.2 성능·품질
- 첫 로딩 2초 이내 (4G), 앱 용량 30MB 이하
- 탭 반응 100ms 이내, 애니메이션 60fps
- **완전 오프라인 플레이** (콘텐츠 앱 내장)
- 접근성: 터치 영역 44×44pt 이상, 명도 대비 4.5:1 이상, 동작 줄이기 설정 존중, 스크린리더 레이블

### 9.3 개인정보·스토어 정책
- MVP는 **회원가입 없음**, 개인정보(이름·이메일·연락처) 수집 없음.
- 원격 로그 전송 시: 무작위 기기 ID만 사용, 개인정보 처리방침 게시, 스토어 '데이터 보안/개인정보 라벨'에 정확히 기재.
- 주 타깃은 성인(Q5). 다만 누구나 설치할 수 있으므로 광고·추적 SDK는 MVP에서 미사용, 연령 등급 '전체 이용가' 목표.
- 스토어 카테고리: **교육** (Q19).
