## 1. UX 원칙

| 원칙 | 의미 | 화면에서의 표현 |
|---|---|---|
| **한 손, 한 번에 하나** | 지하철에서 엄지 하나로 | 주요 조작은 화면 하단 1/3 (엄지 영역), 한 화면에 결정은 하나 |
| **배움은 분명하게, 부담은 가볍게** | 영어공부 앱임을 분명히 (Q19) | 홈에 "오늘 배운 단어"·"복습할 단어"·"외운 단어 수"를 전면에 표시. 다만 실패를 꾸짖는 표현은 쓰지 않음 |
| **틀려도 괜찮다** | 실패가 불쾌하지 않게 | 빨간 X·경고음 대신 흔들림 + 부드러운 진동, 게임 오버 없음 |
| **보상은 실력에서** | 운이 아닌 노력 | 별 = 실수 횟수, 수집품 = 복습 성공 |
| **배울 것은 한 줄로** | 긴 설명 금지 | 단어 카드 = 단어 · 뜻 · 예문 한 줄 |
| **나갈 문은 항상 열어둔다** | 갇힌 느낌 제거 | 모든 화면 좌상단 ✕ / ←, 건너뛰기 상시 노출 |

## 2. 정보 구조 (IA)

```
앱 실행
 └─ 스플래시 (1초 이내)
     └─ [첫 실행] 온보딩 3장 ──┐
                              ▼
     ┌──────────── 홈 = 테마 지도 ────────────┐
     │  상단: 별 합계 · 도감 진척 · ⚙️          │
     │  본문: 스테이지 경로 (1 → 10)            │
     │  특수: 🔁 복습 스테이지 (조건 충족 시)    │
     │  하단 탭: 🗺 지도 | 📖 도감               │
     └────────────────────────────────────────┘
        │ 스테이지 탭          │ 도감 탭           │ ⚙️
        ▼                      ▼                   ▼
   [튜토리얼 1회]          단어 도감            설정
        ▼                   └ 단어 상세(카드)
   퍼즐 화면 (크로스워드/워드서치/복습)
        │ 정답마다 → 단어 카드 (오버레이)
        ▼ 클리어
   완료 리캡 ──[다음 ▶]──→ 다음 퍼즐
        └──[지도로]──→ 홈
```

- **하단 탭은 2개뿐** (지도·도감). 메뉴는 레벨업마다 하나씩 해금(PRD §1.4 "살릴 것"): 도감은 스테이지 3 클리어 후 해금 → 첫 사용자의 선택지를 줄임.
- 테마 선택: MVP는 지도 상단 좌우 스와이프로 테마 전환 (테마 1 클리어 시 테마 2 해금).

## 3. 핵심 사용자 흐름

### 3.1 첫 실행 → 첫 클리어 (목표: 3분 이내)
```
앱 실행 → 온보딩(3장, 건너뛰기 가능) → 지도(스테이지 1 강조·펄스)
→ 스테이지 1 탭 → 크로스워드 튜토리얼(3단계, 실제 격자 위 코치마크)
→ 첫 단어 정답 → 단어 카드 + 자동 발음 → … → 리캡 → [다음 ▶]
```

### 3.2 재방문 (D1~D3)
```
앱 실행 → 지도(현재 스테이지 중앙) → [복습 준비됨 배지가 있으면] 🔁 복습 스테이지 강조
```

### 3.3 막혔을 때
```
퍼즐 중 막힘 → 💡 힌트 ①첫 글자 → ②빈칸 예문 → ③가짜 글자 제거
           → 그래도 막힘 → 다른 단어로 전환(칸 탭) → 그래도 → 건너뛰기(2번 탭)
```

## 4. 화면 명세

> 기준 프레임: **360×640 (Android 소형)** 에서 설계, 390×844 / 430×932에서 확장 확인.
> 모든 수치는 dp(=pt) 기준.

### 4.1 홈 — 테마 지도
```
┌──────────────────────────────┐
│ WORD KINGDOM            ⚙️   │  ← 헤더 56
│ ┌──────────────────────────┐ │
│ │ 오늘 배운 단어 8 · 복습 4 │ │  ← 오늘의 학습 카드 (Q19)
│ │ 외운 단어 21개  [복습하기]│ │
│ └──────────────────────────┘ │
│ 카드 한 벌  ‹ 1/3 ›          │  ← 테마명 + 테마 전환
│ ┌────────────┐┌────────────┐ │
│ │ ★ 18 / 30  ││ 📖 21 / 46 │ │  ← 진척 카드
│ └────────────┘└────────────┘ │
│            (10)              │
│        ( 9)                  │
│   🔁 복습 4단어              │  ← 복습 스테이지 (조건부)
│              ( 8)            │
│          ◉ 7  ← 현재(펄스)   │
│      ( 6)★★☆                 │
│            …                 │
├──────────────────────────────┤
│   🗺 지도        📖 도감      │  ← 하단 탭 56
└──────────────────────────────┘
```
- 경로: 아래(1) → 위(10)로 올라가는 지그재그. 노드 64dp, 노드 아래 제목 + 별.
- 상태: 잠김(🔒, 30% 투명) / 현재(크림색 + 금색 펄스) / 클리어(금색 + 별) / 건너뜀(점선 테두리 + "건너뜀").
- 잠긴 노드 탭 → "이전 스테이지를 먼저 깨 주세요" 토스트 (진입 불가).

### 4.2 크로스워드
```
┌──────────────────────────────┐
│ ✕  3. 왕실 가족    ★★☆ 건너뛰기│  ← 헤더: 나가기 · 제목 · 현재 별 · 건너뛰기
│    2/4 단어                  │
│                              │
│      ┌──┬──┬──┬──┐           │
│      │¹J│ A│ C│ K│           │  ← 격자 (화면 높이 40% 이내)
│      └──┴──┴──┴──┘           │     칸 최대 52dp
│         …                    │
│ ┌──────────────────────────┐ │
│ │ ‹   3 세로 · 5글자     › │ │  ← 단서 바
│ │       여왕; 퀸           │ │     한국어 뜻 22sp Bold
│ │  The ____ lives in a…    │ │     (힌트②일 때 빈칸 예문)
│ └──────────────────────────┘ │
│                              │
│   [Q] [E] [U] [N] [E] [R]    │  ← 글자 타일 52×56, 엄지 영역
│ ┌───────────────────┐ ┌───┐  │
│ │ 💡 힌트: 첫 글자   │ │ ⌫ │  │  ← 힌트 · 지우기
│ └───────────────────┘ └───┘  │
└──────────────────────────────┘
```
**칸 상태 색**

| 상태 | 배경 | 글자 | 용도 |
|---|---|---|---|
| 기본 | 크림 `paper` | – | 빈 칸 |
| 현재 단어 | 연파랑 `blue-soft` | 잉크 | 지금 풀 단어 |
| 커서 | 연파랑 + 파랑 테두리 3dp | – | 다음에 채워질 칸 |
| 정답 고정 | 연초록 `ok-soft` | 진초록 | 맞힌 글자 |
| 오답 | 연빨강 | 빨강 | 0.45초 흔들림 후 원복 |

### 4.3 단어 카드 (오버레이, 하단 시트)
```
│ ┌──────────────────────────┐ │
│ │ [콤보 ×3]                │ │
│ │ queen  (🔊)              │ │  ← 36sp, 자동 발음
│ │ 여왕; 퀸                  │ │  ← 20sp Bold
│ │ The [queen] lives in a   │ │  ← 정답 단어 형광 강조
│ │ castle. (🔊)             │ │
│ │ 그 여왕은 성에 산다.      │ │  ← 예문 해석 (회색, 제안)
│ │ ┌──────────────────────┐ │ │
│ │ │        계속          │ │ │
│ │ └──────────────────────┘ │ │
│ └──────────────────────────┘ │
```
- 등장: 아래에서 올라오며 살짝 튕김 250ms. 배경 딤 60%.

### 4.4 완료 리캡
- 상단: "STAGE 3 클리어" · 제목 · 큰 별 3개(하나씩 0.15초 간격 팝) · 실수/힌트 수
- 중단: "이번 판 단어" 리스트 (🔊 · 단어 · 뜻 · [복습] 태그)
- 하단 고정: [다음 스테이지 ▶] (주) · [지도로] (보조)
- 테마 마지막 스테이지: "🎉 테마 클리어!" + 다음 테마 해금 연출

### 4.5 워드서치
- 상단: 찾을 목록 = **한국어 뜻 칩** (찾으면 영어로 뒤집히며 취소선)
- 중앙: 정사각 격자, 드래그 선택 시 반투명 캡슐 하이라이트
- 보너스 단어: "+ 보너스 BET" 토스트, 칩 영역 하단에 별도 줄

### 4.6 단어 도감
- 테마 탭 → 3열 그리드 카드. 만난 단어: 영어 + 뜻 / 안 만난 단어: `? ? ? ?`
- 단어 상태 배지: 🆕 처음 봄 · 🔁 복습 필요 · ⭐ 마스터
- 상단 "수집품" 가로 스크롤 (복습으로 얻은 카드 문양)

### 4.7 설정
자동 발음 · 효과음 · 진동 (토글) / 튜토리얼 다시 보기 / 학습 기록 내보내기 / 데이터 초기화(2단계 확인) / 개인정보 처리방침 / 버전

### 4.8 빈 상태·오류 상태
| 상황 | 표시 |
|---|---|
| 발음 불가 기기 | 🔊 버튼 비활성 + 1회 토스트 "이 기기에선 발음을 들을 수 없어요" |
| 저장 실패 | 조용히 계속 진행, 설정에 "기록이 저장되지 않는 환경이에요" 표시 |
| 도감 비어 있음 | "첫 스테이지를 깨면 단어가 모여요" + [지도로] |
| 복습 대상 없음 | 복습 노드 미표시 |

## 5. 디자인 시스템 (초안 — G1에서 HTML 시안으로 확정)

### 5.1 콘셉트
**"카드 게임 테이블"** — 짙은 초록 펠트 배경 위에 크림색 종이 카드, 금색 포인트. 테마마다 배경 모티프만 교체(공항 = 남색 활주로, 부엌 = 타일).

### 5.2 색상 토큰
| 토큰 | 값 | 용도 |
|---|---|---|
| `felt` / `felt-2` / `felt-3` | #14322B / #1C443A / #26574A | 배경 |
| `paper` / `paper-2` | #FBF6EA / #EFE6D0 | 칸·타일·카드 |
| `ink` / `ink-soft` | #23201B / #6B6457 | 본문 |
| `gold` / `gold-deep` | #E6B84C / #B98A1F | 주 버튼·별 |
| `blue` / `blue-soft` | #3A7BD5 / #D7E6FB | 현재 단어·커서 |
| `ok` / `ok-soft` | #3C9A6A / #D9EFE2 | 정답 |
| `red` | #C8423B | 오답·복습 태그 |

모든 텍스트/배경 조합 명도 대비 4.5:1 이상 (G1에서 측정표 첨부).

### 5.3 타이포그래피
- 서체: **Pretendard** (한글·영문, OFL 라이선스 → 앱 내장 가능)
- 스케일: 36 (카드 단어) / 28 (화면 제목) / 22 (단서) / 20 / 16 (본문) / 14 / 12 (보조)
- 영어 단어는 카드·리캡에서 **소문자**로 표시 (실제 쓰임 형태), 격자 안은 대문자

### 5.4 간격·모서리
- 4dp 그리드, 화면 좌우 여백 16dp
- 모서리: 칸 8 / 타일 10 / 카드 14 / 시트 20 / 버튼 999(알약)

### 5.5 컴포넌트 목록 (시안 컴포넌트 = 코드 컴포넌트 1:1)
`Button(primary/secondary/text/icon)` · `Cell` · `Tile` · `ClueBar` · `WordCard` · `StageNode` · `StatChip` · `StarRating` · `Toast` · `BottomSheet` · `TabBar` · `Toggle` · `Coachmark`

## 6. 인터랙션·피드백 명세

| 이벤트 | 시각 | 소리 | 진동 (앱) | 시간 |
|---|---|---|---|---|
| 타일 탭 | 눌림 3dp, 칸에 글자 팝 | 딸깍 | light | 80ms |
| 정답 | 칸 초록 물결(왼→오) | 띠링 + 단어 발음 | success | 400ms |
| 오답 | 격자 좌우 흔들림, 칸 연빨강 | 둔탁한 톡 (작게) | warning | 450ms |
| 콤보 3+ | 콤보 배지 확대 | 상승음 | – | 300ms |
| 스테이지 클리어 | 별 순차 팝 + 금가루 | 팡파르(짧게) | success | 1s |
| 힌트 | 공개 글자 반짝 | 반짝 | light | 300ms |

- **동작 줄이기**(OS 설정) 켜져 있으면 흔들림·팝 대신 색 변화만.
- 효과음은 기본 켜짐, 볼륨은 발음보다 작게 (발음이 주인공).

## 7. 접근성 체크리스트
- [ ] 터치 영역 44×44 이상 (격자 칸이 작아지는 7열에서도 칸 사이 탭 영역 보정)
- [ ] 색만으로 상태 구분하지 않음 (정답 칸 = 색 + 글자 굵기, 오답 = 색 + 흔들림)
- [ ] 스크린리더: 칸 "3행 2열, 3번 세로 단어, 비어 있음", 타일 "글자 Q"
- [ ] 글꼴 크기 확대(OS 설정 130%)에서 레이아웃 깨지지 않음
- [ ] 동작 줄이기 대응

## 8. 문구(UX 라이팅) 원칙
- 반말 X, 딱딱한 존댓말 X → **"~해요"체**
- 실패 문구 없음: "틀렸습니다" ✕ → 흔들림만 / 리캡에서 "다시 만나면 기억할 거예요"
- 버튼은 동사로: "계속", "다음 스테이지", "지도로"

## 9. 디자인 검증 계획
1. **G1 전:** HTML 클릭 시안 링크로 3명 5분 테스트 ("첫 단어를 풀어 보세요" 과제 성공 여부)
2. **P5:** 실제 빌드로 10~20명 1~2주 테스트 + 5명 인터뷰
3. 측정: 첫 단어 입력까지 걸린 시간, 튜토리얼 이탈, 힌트를 찾는 데 걸린 시간
